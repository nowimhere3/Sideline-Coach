# AGENT REPORT FINAL-LINK SOP

Whenever an AI Player creates a report:

1. Save the report in the correct project report folder.
2. In the Player's final chat/terminal reply, include the report location.
3. The VERY LAST LINE of the reply must be the complete clickable absolute report path or URL.
4. Do not place commentary after that final link/path.
5. If no report was created, do not fabricate a report link.

Required ending format:

REPORT COMPLETE

C:\absolute\path\to\REPORT-NAME.md

For GitHub-hosted reports, when appropriate:

https://github.com/<owner>/<repo>/blob/<branch>/<report-path>
