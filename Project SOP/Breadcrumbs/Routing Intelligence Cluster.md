## Summary

We discovered that **Conserve** was being asked to communicate too much by itself.

New product direction to preserve:

- Keep **AUTO / MANUAL** as the existing dispatch-mode controls.
- Keep **Refresh** and **+ PATH** where they are.
- Introduce a separate visual grouping called:

**Routing Intelligence**

This grouping sits above the routing-posture controls and visually contains them with a **top-down open-bottom bracket / guide-line treatment**.

## Intended controls inside Routing Intelligence

Two sibling controls:

1. **CONSERVE**
2. **BEST**

Each control uses:

- the same **square actuator / lamp-style button**
- light-based **on / off** state
- adjacent text label
- adjacent **info icon** for explanation / tooltip / learn-more copy

## Core meaning

This grouping communicates:

- these are **routing posture / coaching preferences**
- they are **not** the same thing as AUTO / MANUAL authority
- AUTO / MANUAL stays about **how dispatch authority works**
- Routing Intelligence stays about **how Sideline thinks / coaches / optimizes**

## Why this matters

This solves the earlier problem where a single **Conserve** button had to carry too much conceptual weight.

Instead of one overloaded control, we now have:

- a parent concept: **Routing Intelligence**
- child options underneath it: **Conserve** and **Best**

This is cleaner visually and more scalable for future routing/coaching behavior.
