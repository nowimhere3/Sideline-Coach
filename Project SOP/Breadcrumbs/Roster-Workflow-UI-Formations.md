# Roster / workflow UI — formation representation (future)

Recorded 2026-09-22 during the mobile Expanded Scoreboard pass. Not implemented; not part of that task.

Two formation concepts still lack explicit representation in the roster/workflow UI:

- **B-Team / worker formation**: which Players make up the backup/worker depth and how that formation is shown.
- **Scout formation**: which Scouts are deployed together as a formation and how that formation is shown.

Both already exist as routing and eligibility concepts (see `BREADCRUMB -- SIDELINE-PLAY-COMPILER-AND-INTELLIGENT-ROUTING.md` and `BREADCRUMB- AI-USAGE-SCORECARD.md`). What is missing is how the roster and workflow surfaces present them. Treat this as a UI representation gap only. Do not infer routing policy from it.
