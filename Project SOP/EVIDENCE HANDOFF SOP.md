# EVIDENCE HANDOFF SOP

## RULE

**Do not make the Human Head Coach assemble evidence the machine can already access.**

## INTERNAL REPOSITORY EVIDENCE

If required reports or files already exist inside the repository:

1. Find the correct files.
2. Verify the correct versions.
3. Reference them **in place**.
4. Give the receiving agent the **exact absolute paths**.

Do not copy, rename, bundle, or ask the human to gather them unless technically necessary.

## EXTERNAL EVIDENCE

If required evidence exists outside the repository and the receiving agent cannot access it:

1. Compile it into a clean package.
2. Create clear filenames and a manifest if needed.
3. Give the Human Head Coach **one bundle**.
4. Give **one exact destination folder**.
5. Verify staging before writing the final agent prompt.

## PREMIUM AGENT RULE

**Stage first. Prompt second.**

Every referenced input must include:

`NAME + EXACT PATH`

If an expected file is missing or inaccessible, the receiving agent must **STOP immediately** and report the missing path.

Do not search the repository blindly.
Do not reconstruct missing evidence with premium reasoning.

## NORTH STAR

**If the machine can access the evidence, the human does not assemble the evidence.**

**Make the machine carry the complexity.**
