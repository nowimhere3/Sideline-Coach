6. **What lifecycle/session restrictions exist?**
   - **Inactivity Timeout:** Cloud Shell terminates after **60 minutes** of inactivity.

   - *"No daemon proxy"* avoids replicating Google's existing authenticated HTTPS proxy.

## 3. MINIMUM ADAPTER

The adapter is a 5-line environment check inside the pure `src/preview-discovery.ts` module:

```typescript
export function resolveClientUrl(port: number, localUrl: string): { clientUrl: string; directTabOnly: boolean } {
  // Google Cloud Shell Web Preview
  if (process.env.WEB_HOST) {
    if (port < 2000 || port > 65000) {
      throw new Error(`Cloud Shell Web Preview requires ports between 2000 and 65000 (detected ${port}).`);
    }
    return {
      clientUrl: `https://${port}-${process.env.WEB_HOST}`,
      directTabOnly: true // Google CSP frame-ancestors prevents iframe embedding
    };
  }

  // Local desktop default (Codespaces and remote SSH resolve via vscode.env.asExternalUri in the Stadium)
  return {
    clientUrl: localUrl,
    directTabOnly: false
  };
}
```

## 4. PHONE-REACHABILITY FINDING

| Assertion | Evidence Classification | Detail |
| :--- | :--- | :--- |
| **Authentication Requirement** | **VERIFIED** | Google Web Preview URLs (`https://$PORT-$WEB_HOST`) are **not public**. Access is gated by Google Account OAuth2. Unauthenticated requests redirect to `accounts.google.com`. |
| **Second Device / Phone Access** | **VERIFIED** | Dad **can** open the preview URL on his mobile browser (Chrome/Safari) **if and only if** that mobile browser is signed into the **same Google account** that owns the Cloud Shell instance. |
| **Cross-Origin Iframe Embedding** | **VERIFIED** | Google Web Preview enforces `Content-Security-Policy: frame-ancestors *.google.com *.cloud.google.com` and `X-Frame-Options: SAMEORIGIN`. It **cannot** be rendered inside the Sideline Coach dashboard iframe on an external domain. |
| **UI Presentation on Phone** | **INFERENCE** | On Dad's phone dashboard over the relay, tapping the **"Open in new tab ↗"** link will open the Google-authenticated preview cleanly. Attempting to render it inside an iframe will produce a blank frame / CSP block. |
| **Enterprise IAM / CAA Policies** | **UNKNOWN** | Corporate Google Workspace accounts with Context-Aware Access (device certificates, company IP ranges) may block personal mobile devices even with valid credentials. |

## 5. ANY REQUIRED R11 CORRECTION

**No architectural correction is required.**

Opus's S57.33 adjudication anticipated this exact situation by establishing two defensive invariants:
1. *"Open in new tab must always be visible."*
2. *"A page can't reliably detect a blocked cross-origin iframe... Codespaces login cookies may fail inside an iframe."*

The only minor refinement to `PreviewEndpoint` is an optional presentation flag:

```typescript
export interface PreviewEndpoint {
  // Existing S57.33 fields:
  readonly gameId: string;
  readonly stadiumId: string;
  readonly localUrl: string;
  readonly clientUrl: string;
  readonly port: number;
  readonly source: 'declared' | 'remembered' | 'detected';
  readonly ownership: 'declared' | 'verified' | 'confirmed';
  readonly status: 'active' | 'stale' | 'offline';
  readonly observedAt: number;

  // Optional additive metadata:
  readonly directTabOnly?: boolean; // Set true for Cloud Shell
}
```
