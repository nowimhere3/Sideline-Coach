EXACT RULES & CONTRACTS IMPLEMENTED

### 1. Authoritative Session Reconciliation Rule
In `backfillConsole(instanceId)`:
```javascript
const generation = (consoleBackfillGeneration.get(instanceId) || 0) + 1;
consoleBackfillGeneration.set(instanceId, generation);
const sessionAtRequest = consoleActivity.get(instanceId)?.sessionKey;

const data = await api(`/api/player-activity?gameId=${encodeURIComponent(gameId)}&instanceId=${encodeURIComponent(instanceId)}`);
if (gameId !== currentGameId || !liveConsoleEnabled()) return;
if (consoleBackfillGeneration.get(instanceId) !== generation) return;

const existing = consoleActivity.get(instanceId);
// Genuinely late response guard: only discard if live SSE activity for a DIFFERENT session
// arrived while this HTTP backfill was in flight:
if (existing && existing.sessionKey && existing.sessionKey !== sessionAtRequest && data.sessionKey && existing.sessionKey !== data.sessionKey) {
  return;
}

// Authoritative reconciliation: consoleBucketFor resets bucket entries and cursor
// whenever data.sessionKey differs from the cached session.
const bucket = consoleBucketFor(instanceId, data.sessionKey, data.epoch);
for (const entry of Array.isArray(data.entries) ? data.entries : []) upsertConsoleEntry(bucket, entry);
bucket.backfilled = true;
refreshConsoleView(instanceId);
```
- **Rule:** The server backfill is authoritative. If `data.sessionKey !== existing.sessionKey`, the client resets to the server's session key, clears the old transcript, and adopts the server's entries.
- **Protection:** A response is only discarded if `existing.sessionKey !== sessionAtRequest` (meaning a new session started via SSE *after* the HTTP fetch was launched) AND `existing.sessionKey !== data.sessionKey`.

### 2. Scout Terminal Eligibility Rule
In `renderPlayStrip(view, record)`:
```javascript
const isTerminalEligible = liveConsoleEnabled()
  && view.executionType !== 'scout-formation'
  && record.typeName !== 'Scout'
  && (view.state === 'working' || view.state === 'starting' || view.state === 'finished');
```
- Scout formations and Scout player types are barred before `play-terminal-toggle-row` is constructed.
- Controlled agents (Claude, AntiGravity, Codex) with `transport === 'Controlled'` retain full terminal eligibility.

### 3. Collapsed-First Rendering Rule
In `renderPlayStrip`:
```javascript
const copyState = consoleCopyState(view.instanceId);
for (const [label, mode] of [['Copy All', 'all'], ['Copy New', 'new']]) {
  const button = stripButton(label, `${label} terminal content for ${name}`, `console-copy-${mode}`, () => void copyConsole(view.instanceId, mode, button));
  const available = mode === 'all' ? Boolean(copyState.all) : Boolean(copyState.fresh);
  button.disabled = !available;
  button.title = mode === 'all'
    ? (available ? '' : 'Nothing to copy yet')
    : (available ? 'Copy activity since your last copy' : (copyState.all ? 'No new activity since your last copy' : 'Nothing to copy yet'));
  controls.appendChild(button);
}
```
- When `syncConsoleBody(body)` runs upon initial expansion, any in-memory entries are rendered immediately.
- The copy buttons read `consoleCopyState` synchronously during DOM construction, enabling `Copy All` immediately if entries exist.
