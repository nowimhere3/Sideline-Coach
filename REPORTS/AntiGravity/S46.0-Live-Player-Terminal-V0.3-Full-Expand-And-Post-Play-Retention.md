## 1. Executive Summary

Live Player Terminal V0.2 proved the end-to-end sanitized exact-Player activity pipeline in the real field.  
**Live Player Terminal V0.3** locks in this capability with a production-grade viewing and retention experience:

1. **Desktop Large Workspace**: When expanded, `.play-console` occupies approximately half the viewport (`height: 50vh; min-height: 280px; max-height: calc(100vh - 140px);`), with a scrollable body (`flex: 1 1 auto; overflow-y: auto;`).
2. **Mobile Fullscreen Layer**: On narrow screens (`max-width: 619px`), expanding the terminal transforms it into a full-screen overlay (`position: fixed; inset: 0; z-index: 1000; width: 100vw; height: 100vh; height: 100dvh;`), with safe-area padding for mobile notches and status bars.
3. **Dedicated Terminal Header & Immediate Collapse**:
   - Header left: Context indicator displaying `Live Terminal · ${name}`.
   - Header right: Top-right `Collapse` button (`console-toggle`), sticky on mobile so the user never has to scroll through output to collapse.
   - Collapsed state: Compact, right-aligned `Expand` button in the utility row with unchanged, approved button styling.
4. **Bottom-Left Copy Controls**: `Copy All` and `Copy New` reside in the footer (`.play-console-actions`), aligned to the bottom-left (`justify-content: flex-start;`).
5. **Post-Play Retention**: When a Play completes, an expanded terminal remains pinned and accessible even after the standard 30-second rich execution window (`RICH_FINISHED_MS`) expires, eliminating premature vanishing while the operator is inspecting logs.
6. **Three Strict Release Conditions**:
   - **(a) Manual Collapse**: Tapping `Collapse` immediately releases pinning and removes the expired strip if the rich window has ended.
   - **(b) Post-Completion Copy**: Successful `Copy All` or `Copy New` *after* completion releases the pinned terminal and removes the expired strip. Copying *mid-play* does **not** collapse the terminal.
   - **(c) Next Play Continuity**: Starting a new Play on the same player rotates the transcript, resets the pinning flag, and **stays expanded** so the operator maintains unbroken visibility across turns.
7. **Zero Regression**: Preserves exact-instance separation, Scout exclusion, security redaction, and Preview Reports typography (`var(--reader-font-size)`, `var(--reader-line-height)`).

### C. Post-Play Pinning & Lifecycle Releases (`src/public/index.html`)

- Added `const consolePinnedByInstance = new Set();`.
- When a play completes (`view.state === 'finished'`) while expanded (or when expanded during finished state), the instance is added to `consolePinnedByInstance`.
- `renderPlayStrip`: If the standard `stripCopy` decays because `!rich && !reportReady`, but the terminal is pinned (`consolePinnedByInstance.has(view.instanceId)`), a truthful `{ glyph: '✓', word: 'Finished', summary: ... }` copy is supplied to keep the strip and expanded terminal mounted.
- `copyConsole`: If `currentView && currentView.state === 'finished'`, successful copy clears `consolePinnedByInstance` and `consoleExpandedByInstance`, cleanly collapsing and unmounting the expired strip. If the play is still active (`working` or `starting`), copy does not collapse the terminal.
- Next Play: When a new play starts (`starting` or `working`), `consolePinnedByInstance` is cleared, while `consoleExpandedByInstance` is preserved, allowing unbroken live terminal monitoring into the next turn.
