## HIERARCHY BEFORE / AFTER

### WAS (Flat Sibling Cards)

Settings rendered developer controls as separate, equal top-level sibling cards:

```text
SETTINGS
├─ Dev Mode (top-level card)
├─ View Player Terminal (top-level card, Dev Mode gated)
├─ Terminal Success Retention (top-level card, Dev Mode + console gated)
├─ Advanced Player Discovery (top-level card, Dev Mode gated)
├─ Scout Intelligence (top-level card)
│   └─ Dev Mode · Field one READY Scout (visible even when Dev Mode is OFF)
├─ Coach Routines (top-level card, Dev Mode gated)
└─ Game Setup (top-level card)
```

Ownership was completely obscure. Terminal Success Retention and Advanced Player Discovery looked like disconnected top-level settings rather than options belonging to the Terminal feature family. In Scout Intelligence, the developer-only one-Scout formation operator leaked into Dad's view even with Dev Mode turned off due to CSS specificity overriding `[hidden]`.

### IS (Nested Feature Hierarchy)

Settings expresses clear visual hierarchy using Sideline's established parent-to-child card grammar:

```text
SETTINGS
├─ Dev Mode (master visibility gate)
├─ VIEW PLAYER TERMINAL (Parent Feature Card)
│   ├─ View Player Terminal toggle
│   └─ .settings-children
│       ├─ Terminal Success Retention (Child Setting Card)
│       └─ Advanced Player Discovery (Child Setting Card)
├─ SCOUT INTELLIGENCE (Parent Feature Card)
│   ├─ OpenRouter Credential (Normal Controls)
│   ├─ Scout Bootstrap / Tryouts (Normal Controls)
│   └─ Dev Mode · Field one READY Scout (Dev Mode Gated Child Subsection)
├─ Coach Routines (Dev Mode Gated Feature Card)
└─ Game Setup (Canonical Folder Controls)
```

Child cards use `.card.settings-card.settings-child-card` with `background: var(--card-2)`, `border: 1px solid var(--line)`, `border-radius: 14px`, and inset padding `12px 14px` (`10px 12px` on narrow screens `<=460px`), directly matching `.player` nested inside `.roster`.

## DEV MODE GATING BEHAVIOR

| Surface | Dev Mode OFF | Dev Mode ON |
|---|---|---|
| **View Player Terminal** (Parent) | **Absent** (`hidden = true`) | **Visible** (`hidden = false`) |
| **Terminal Success Retention** (Child) | **Absent** (enclosed in hidden parent; `hidden = true`) | Visible inside parent card **only if** View Player Terminal toggle is ON |
| **Advanced Player Discovery** (Child) | **Absent** (enclosed in hidden parent; `hidden = true`) | Visible inside parent card as part of the Terminal feature family |
| **Scout Intelligence** (Normal) | **Visible** (if OpenRouter available) | **Visible** (if OpenRouter available) |
| **Dev Mode · Field one READY Scout** (Child) | **Absent** (`hidden = true`, styled with `.scout-credential-body[hidden] { display: none !important; }`) | **Visible** inside Scout Intelligence card (if OpenRouter available) |
| **Coach Routines** | **Absent** (`hidden = true`) | **Visible** |
