## IMPLEMENTATION

### 1. Activity Category Contract (`src/player-activity.ts`)
```typescript
export type ActivityCategory = 'working' | 'message' | 'command' | 'tool' | 'declined' | 'result' | 'channel' | 'output';

export const ACTIVITY_CATEGORIES: readonly ActivityCategory[] = ['working', 'message', 'command', 'tool', 'declined', 'result', 'channel', 'output'];
```

### 2. Whitespace-Preserving Sanitization (`src/player-activity.ts`)
```typescript
export function sanitizeActivityText(value: unknown, category: ActivityCategory, streaming = false): string {
  let text = String(value ?? '').slice(0, REGEX_INPUT_CAP).replace(ANSI, '').replace(CONTROL, '');
  text = redactSecrets(text);
  const max = category === 'message' ? ACTIVITY_MESSAGE_MAX : ACTIVITY_LINE_MAX;
  if (category === 'message') {
    text = text.replace(/\r\n?/g, '\n').replace(/\n{3,}/g, '\n\n');
    if (!streaming) text = text.trim();
  } else if (category === 'output') {
    text = text.trimEnd();
  } else {
    text = text.replace(/\s+/g, ' ').trim();
  }
  return text.length > max ? `${text.slice(0, max - 1)}…` : text;
}
```

### 3. Browser Console Label & Placeholder (`src/public/index.html`)
```javascript
const CONSOLE_LABELS = { working: 'WORKING', message: 'MESSAGE', command: 'COMMAND', tool: 'TOOL', declined: 'DECLINED', result: 'RESULT', channel: 'CHANNEL', output: 'OUTPUT' };

  if (view.executionType === 'direct-shell') return 'Waiting for live execution activity…';
  if (record.transport && record.transport !== 'Controlled') return 'Live activity is only available for controlled Players.';
  return 'Waiting for live execution activity…';
};
```

## INVARIANTS VERIFIED

1. **Category Acceptance**: `ACTIVITY_CATEGORIES.includes('output')` is true; `PlayerActivityStore.record` accepts `output` and assigns sequential monotonic IDs.
2. **Whitespace Preservation**:
   - Leading indentation (`    nested detail`) survives unmodified.
   - Hierarchy (`  modified-file.txt`) survives unmodified.
   - Multiple internal spaces (`two  spaces  internal`) are NOT collapsed into single spaces.
3. **Trailing Whitespace Removal**: Trailing spaces and trailing tabs are trimmed cleanly.
4. **Duplicate Retention**: Identical consecutive `output` lines are both recorded with distinct monotonic sequence numbers; neither is suppressed.
5. **ANSI & Control Stripping**: Terminal escape sequences (`\u001b[32mPASS\u001b[0m\u0007`) are stripped before storage.
6. **Secret Redaction**: Auth headers, bearer tokens, API keys (`ghp_...`, `sk-proj-...`) are masked with `[redacted]`.
7. **Line Cap Enforced**: Lines exceeding 240 characters are truncated at 239 characters with a trailing `…`.
8. **Unknown Categories Rejected**: Unrecognized categories return `undefined` and are dropped at the store boundary.
9. **Existing Categories Unaltered**:
   - `command` still collapses internal whitespace and suppresses consecutive duplicates.
   - `tool` still suppresses consecutive duplicates.
   - `message` still coalesces streaming chunks under identical sequence numbers.
   - `output` never enters the streaming coalescing path even if `streaming: true` is passed.
10. **Browser Labeling**: `CONSOLE_LABELS.output` maps to `'OUTPUT'`.
11. **Direct-Shell Eligibility**: `isTerminalEligible` remains unchanged and continues to recognize direct-shell terminal execution.
