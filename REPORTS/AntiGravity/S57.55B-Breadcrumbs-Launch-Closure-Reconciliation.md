# P0 — TRUE LAUNCH BLOCKERS

*A true launch blocker means a real buyer who purchases or installs Sideline Coach cannot use the core advertised product.*

### BC-003: Remote Access Fresh-Install Zero-Setup Provisioning (Stage 5F / 5P2)
- **What Fails for a Real Buyer?**  
  If Remote Access is advertised as a core launch feature, a user downloading the extension from the VS Code Marketplace or GitHub Release will click "Pair Phone" and experience **complete failure**. The required relay enrollment credential (`beta-enrollment.json`) only exists because developers placed it manually in their personal profile directory. On a fresh machine, the relay refuses connection.
- **Why It is P0 (Conditional):**  
  This is a **P0 Blocker ONLY IF Remote Access is a Day 1 advertised feature**.
- **The Escape Hatch:**  
  If Dad designates Remote Access as **"Private Beta / Developer Preview"** for V1, this drops immediately to **P2**, unblocking the entire release.
