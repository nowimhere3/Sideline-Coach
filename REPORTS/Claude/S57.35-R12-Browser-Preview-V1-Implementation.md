## R12 delta compliance

1. **Required environments:** Windows, WSL/SSH, Codespaces all go through the single `asExternalUri` bridge. Nothing is environment-specific.
2. **No Cloud Shell support in R12:** nothing Cloud Shell-specific was added.
3. **`PreviewEndpoint` stays environment-neutral:** the bridge is an injected `toClientUrl(localUrl) → { url, directTabOnly? }`. A Cloud Shell adapter (`port + WEB_HOST → Web Preview URL`, `directTabOnly: true`) plugs in there with no model change. Test P7 exercises this path.
4. **`directTabOnly?: boolean` preserved:** it is carried end to end, and the dashboard shows a tab link instead of a frame when it is set.
5. **Future phone invariant preserved:** the `remote-viewer` reason is the seam a later Remote stage replaces. V1 exposes no URL to phones.

## Discovery and ownership

- **Order:** `.sideline/game.json` `previewUrl` (http/https only) or `previewPort`, then the `package.json` dev script (`dev`/`start`/`serve`/`develop`).
  - Explicit `--port` / `-p` / `PORT=` values come first, then a literal `port` in `vite.config.*`, then framework defaults (Vite 5173, Next 3000, CRA 3000, Astro 4321, Angular 4200, …), plus the next ports for servers that auto-increment. At most 8 candidates.
- **Probe:** TCP on `127.0.0.1` and `::1`, then an HTTP (or HTTPS) check. URLs always use `localhost`.
- **Ownership:** the listening process's command line / cwd is checked on Windows (`netstat` + `Win32_Process`), Linux (`/proc`) and macOS (`lsof`/`ps`).
  - `verified`: the listener's path is under the Game root.
  - `foreign`: another project's `node_modules`. Skipped.
  - `unverified`: no proof either way. Offered, with a notice in the dashboard.
- **Remembered confirmation (R11 "remembered" step): deferred.** Instead of a confirm-and-remember flow, V1 rejects provably foreign servers and labels unprovable ones. The declaration file is the durable override. A confirm-once flow would need a mutation route plus storage, so it's left for when field use shows it's needed.

## Known limits (V1, by design)

- Presets resize one frame. CSS responsive layouts react, but there is no touch or mobile browser emulation. The footnote says so.
- **Codespaces:** the framed app may fail on GitHub's login cookie or on Vite's allowed-hosts check. **Open in new tab** is always visible. If field proof shows the frame never works there, set `directTabOnly` for `remoteName === 'codespaces'`, a one-line change in `previewClientUrl`.
- On Windows the ownership check starts PowerShell once per live candidate, about 1 second, and only when Dad clicks.
