## What was built

### Daemon: `src/control-plane/daemon.ts` (Option A, parity with `routingMode`)

- `private routingPosture: RoutingPosture = 'balanced'`, in memory. A daemon restart returns to `balanced`, exactly as `routingMode` returns to `auto`. No preferences persistence was added.
- `private setRoutingPosture(posture)` is the single mutation seam, and the actuator is currently its only caller. A future alarm policy could call it, and every client's lamp would follow the broadcast with no UI change. It never touches Scarcity.
- **`POST /api/route`** accepts `{ "posture": "balanced" | "conserve" }`.
  - Anything else (`fast`, `sure`, wrong case, non-strings) is ignored, following the endpoint's existing convention for `mode`, and the true state is echoed back.
  - Posture and `mode` are independent.
  - The response carries `routing.posture`, and the existing `status` `routing-change` broadcast resynchronizes every client.
- **Status:** `routing.posture`, next to `routing.mode`, plus a top-level `routingPosture` beside `routingMode`.
- **Engine seam:** the shadow recommendation now passes `posture: { value: this.routingPosture, source: 'coach-default' }` into `recommendRoute()`. This is the one seam used by the Dev preview, the Film digest at dispatch, and the dormant R8 advisory.

**Responsive behavior:**
- The band sits in an inline-size container (`.routing-bar-frame`). A3 collapses at ≤ 560 px of band width, with an `@supports` + `@media (≤ 619px)` fallback for browsers without container queries.
- A4 and A5 are distinct grid cells inside `.conserve-control`, which wraps as one unit. The actuator never separates from its label.
- The band stays a wrapping flex row, so `+ PATH` can wrap but never overlap. This keeps the existing S3-UI-1 contract.

**Styling:**
- **Actuator:** a 44 × 44 dark housing with bevel, inner shadow and drop shadow.
- **OFF lamp:** unlit grey glass (not dimmed or disabled-looking, with hover and focus rings).
- **ON lamp:** turquoise `#2ee2d4` with a restrained two-step glow and a faint inner tint in the housing. The row itself is not lit.

**Info control:**
- The hover `title` uses the approved sentence.
- Clicking toggles an inline explainer (the existing `routine-explainer` style) with the approved four-part copy, `aria-expanded` and `aria-controls`.
- No internals (Brier, bins, Film, thresholds, weights) are exposed.

**Wiring:**
- `currentRoutingPosture` is restored from `status.routing.posture` on every status render, which covers browser refresh.
- A click posts `{ posture }`, optimistically lights the lamp, adopts the daemon's echoed truth, and reverts with a toast if the request fails.
- Status renders do not override an in-flight change.
- There is no `localStorage` or any second browser truth.
