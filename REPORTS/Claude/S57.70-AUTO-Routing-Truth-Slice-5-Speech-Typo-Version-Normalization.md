- Number words `zero`–`twenty` and digit tokens, optionally joined by `point`/`dot` (or adjacent: `five six`), form one maximal run. The run converts to digit tokens only if the whole run equals a complete maximal digit run of a live model alias (e.g. `5 6`, `6 1`, `3 8`).
