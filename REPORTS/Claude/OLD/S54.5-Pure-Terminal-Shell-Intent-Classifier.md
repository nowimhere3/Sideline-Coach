## CLASSIFIER API

```ts
classifyShellIntent(prompt: unknown):
  | { kind: 'shell'; command: string; intentClass: 'inspect' | 'project-command'; rule: string }
  | { kind: 'reasoning'; reason: ShellIntentReason }
export const SHELL_INTENT_RULES: readonly string[]
```

- `command` is the input trimmed of **ASCII** whitespace only, byte for byte. The classifier never rewrites text. Play 5 must send `verdict.command`, not the raw prompt, because a trailing newline is trimmed.
- `reason` is diagnostic only (17 codes, e.g. `request-language`, `metacharacter`, `denylisted`, `secret-path`, `unknown-flag`). No caller should branch on it.
- **The only import is `checkTerminalCommand`.** It has no `vscode`, `fs`, process, network, clock or randomness. (`terminal-player.ts` pulls in `player-activity.ts`, which uses `node:crypto` for hashing. That is a transitive dependency of the boundary itself, not something the classifier calls.)

## GRAMMAR AND ACCEPTANCE PHILOSOPHY

**Closed rules, no score, no similarity, no "ask" outcome.** `shell` requires every gate to hold:

| Gate | Requirement |
|---|---|
| Shape | 1–160 chars after trimming ASCII whitespace; single physical line; printable ASCII only (kills zero-width, NBSP, BOM and homoglyph tricks); no code fence; no prompt mark (`$ > # % PS>`); single spaces only |
| Tokens | Each token uses only `A-Za-z0-9 _ . / \ -`. No quotes, `=`, `$`, `%`, `~`, `*`, `?`, `:`, brackets, pipes, redirects, chaining, backticks |
| Deny overlay | Independent of the grammar: destructive, network, shell-in-shell and remote executables; force/destroy flags (`-f --force --hard -rf -y -c -e`…); secret-shaped names (`.env`, keys, certs, credentials, tokens, ssh); any `.git/` path |
| Prose veto | About 180 request and prose words (please, why, can, explain, fix, run-for-me language…). A contradiction is a veto, not a lower score |
| Grammar row | Exact, **case-sensitive** leading words, closed flag set, bounded positionals that must be path-shaped or a ref (`HEAD main master develop`) |
| Final gate | `checkTerminalCommand(text).ok`, so it is a strict subset of the explicit boundary |

**Accepted grammar** (`inspect`, read-only):
- `git status|diff|log|show|branch` with closed flags and at most 1–2 path-or-ref positionals; `git log` accepts `-n N` or `-N` with N ≤ 100.
- Version probes for `git node npm pnpm yarn python dotnet cargo`.
- Bare `dir ls pwd whoami hostname Get-Location Get-ChildItem`.

**Accepted grammar** (`project-command`):
- `npm|pnpm|yarn test`, and `run test|build|lint|check|compile|typecheck`.

**Shrunk relative to the S53.0 seed** (all false negatives by design, widening needs a human decision):
- `npm install|ci` is dropped (network plus lifecycle scripts, and S53.0 itself called network-fetching ineligible).
- `cat|type|Get-Content`, `git remote`, `tasklist`, `Get-Process` and `Test-Path` are dropped.
- Quoted arguments are dropped.
- The `go` row is dropped: `go` is an English word (found by my own review, below).
- `cargo`, `dotnet` and `go` build/test rows are dropped; only version probes remain.

## FALSE-POSITIVE PROTECTIONS (the second review)

I asked "can Dad type ordinary conversational English that this would read as permission to execute?" and answered it with evidence, not by eye.

- **Curated prose corpora, about 150 sentences:** questions ("Can you run git status and tell me what changed?", "Why did npm test fail?", "Should I run npm install?"), explain requests, write-me-a-command requests, imperative and polite requests, and prose with code fences, prompt marks, backticks or multiple lines. None is `shell`.
- **40,000 seeded conversational sentences** built from 19 leads × 15 real commands × 19 tails. None is `shell`.
- **Exhaustive sweep:** every 1–3 token sentence starting with a real executable, drawn from about 230 English words plus grammar tokens (**1,188,645 sentences**). 113 were accepted, and every accepted one contained only grammar tokens or explicit path-shaped tokens. **Zero** English word ever rode into an accepted command.
- **Mutation property over every accepted command:**
  - Appending prose, junk, `--force`, secret names or a traversal path flips it to NOT terminal.
  - Prefixing "please", "can you run", "why does", "$" or "sudo" flips it.
  - Wrapping it in quotes, backticks, parentheses, a fence, `?`, `.` or `!` flips it.
  - A second line, zero-width, NBSP, NUL, tab or double space flips it.
  - Changing case flips it.
- **Real defects the review found and I fixed before PASS:**
  1. `git diff src/a.ts.` (a sentence-ending period) was accepted. A trailing `.` on a path token is now refused.
  2. `git diff .git/config` was accepted. `.git/config` can hold remote URLs with embedded credentials. `.git` path segments are now refused.
  3. `git branch -r` was unreachable because I had `-r` in the deny-flag list. It is now consistent.
  4. `go version` was refused by my own prose veto (`go` is a word). I dropped the row rather than special-case it.
  5. My purity test tripped on the deny-list string `stop-process`. That was a test-pattern bug (fixed to match API usage, not bare words).

## REMAINING UNKNOWNS

- **No independent adversarial review yet.** S53.0's completion gate asked for a second Player (Codex High) to reproduce and attack the corpus. My second review is self-review plus the exhaustive sweeps above. I recommend that independent pass **before** Play 5 wires it.
- **Pager behavior.** `git diff|log|show|branch` can open a pager in an interactive terminal if output exceeds one screen. Whether the Terminal transport copes is unverified. It is a hang risk, not a wrong-execution risk. Play 5 should check it. The cheap fix is to restrict AUTO to bounded forms (for example `git log` requires `-n` or `--oneline`).
- **`npm run <script>` names are project-defined.** `check`, `compile` and `build` are only as safe as the Game's `package.json`. This follows S53.0's approved seed. Play 5 already restricts to a Coach-managed Terminal.
- **Trailing-newline trimming.** Play 5 must send `verdict.command`, not the raw prompt.
- **Bare single words are commands.** A message that is exactly `ls`, `dir`, `pwd`, `whoami` or `hostname` classifies as `shell`. That is intended and unmistakable, but worth Dad's awareness when Play 5 lands.
- **One unexplained flaky failure in full-suite run 1**: `scout-continuation.test.mjs` "real Control Plane chain returns COMPLETE Scout evidence…".
