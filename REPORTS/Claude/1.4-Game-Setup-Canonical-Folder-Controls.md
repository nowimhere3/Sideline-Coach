PASS. S10.0 is implemented: the Game Setup Settings card is live (Reports

# WHAT CHANGED

1. Two new authoritative HTTP routes in `src/control-plane/daemon.ts`:
   - `POST /api/games/filesystem/choose` — validates `{ gameId, kind, path }`,
     verifies the path is live via `game.files.check` (the exact same
     Stadium-authoritative boundary the file browser already trusts), then
     calls `GameFilesystemCoordinator.recordHumanChoice`. For `kind:
     'reports'` it also pushes the updated contract to the Stadium
     (`applyGameFilesystemContract`, the existing S7 apply/watch mechanism).
     `kind: 'sop'` records only — never applied remotely, never mutates a
     Game.
   - `POST /api/games/filesystem/restore` — calls
     `GameFilesystemCoordinator.clearChoice`, then reuses S6's own
     `reconcile()` pass (the same one `/reinspect` already used) so automatic
     detection resumes immediately when the Game is connected.
2. `src/public/index.html`:
   - Game Setup Settings card replaced with two rows (Reports folder, SOP /
     onboarding folder), each showing the friendly path, the friendly state
     text, a `Browse / Change` button, and a conditional `Restore detected
     folder` button.
   - `syncGameSetupSettings(status)` renders directly from `status.gameSetup`
     (already live on every SSE status push) — no new fetch, no polling.
   - Two new `pathActionProviders` entries, `SETTINGS_REPORTS` /
     `SETTINGS_SOP`, added to the existing neutral Browse Game controller.
     Each is folder-only (`eligible: entry.kind === 'folder'`), offers one
     primary action ("Use as Reports/SOP folder") gated by that eligibility,
     plus the existing "Copy Game-relative path" action so a file row's menu
     is never empty.
   - `chooseCanonicalFolderAction(kind, entry)` calls `/choose` using
     `gameBrowser.gameId` (captured when the picker opened, never the ambient
     `currentGameId`), then `refresh()`s status on success.
   - `Restore detected folder` buttons call `/restore` and `refresh()`.
   - Minimal CSS for `.gamesetup-*` classes, matching the existing
     `settings-card` / `routine-browse` visual language.
3. New test file: `test/s10-0-game-setup-canonical-folder-controls.test.mjs`
   (23 tests, all real-daemon HTTP integration tests, no mocks of the
   coordinator itself).

No changes to S6 detection logic, S7 apply/watch, S8 ensure/bootstrap, S9
destination resolution, `coach.reportGlobs`, `ReportPublisher`, provider
lanes, or Game identity.

# REPORTS FOLDER OVERRIDE

`Browse / Change` opens the existing neutral Browse Game sheet in
`SETTINGS_REPORTS` mode. Navigating is inert; only the row/folder action
"Use as Reports folder" (primary, folder-only) calls `/choose` with
`kind: 'reports'`. On success the contract's `reports` folder becomes
`{ path, provenance: 'human', state: 'ready' }` and existing lanes are
preserved unchanged (same lane keys/folder names, now resolved under the new
root — see S9 CONVERGENCE below).

# SOP FOLDER OVERRIDE

Same mechanism, `kind: 'sop'`, `SETTINGS_SOP` browse mode, "Use as SOP
folder" primary action. SOP choice is never applied to any Stadium (the S7
apply RPC only ever carries `reports` + `lanes`) and never touches the
Reports contract.

# HUMAN AUTHORITY / PROVENANCE

`recordHumanChoice` sets `provenance: 'human'`, which S6's own
`verifyExistingChoice` in `decideReportsRoot`/`decideSopRoot` treats as an
existing decision to be *verified*, never re-decided — confirmed by test
S10-13 (a competing candidate appearing after the human's choice does not
dislodge it).

# AUTHORITATIVE SAVE / VALIDATION

`/choose` validation order: `gameId` required → `kind` ∈ {reports, sop} →
non-empty path ≤240 chars → Game-relative normalization (backslashes →
forward slashes, leading `./` stripped, trailing slash stripped — spaces and
casing preserved exactly) → known Game → connected Stadium → Stadium
supports `game.files.v1` + `game.filesystem.v1` → **live**
`game.files.check` RPC confirms `state === 'folder'` → only then
`recordHumanChoice`. A file, a missing path, a blocked/escaping path, or a
folder that vanished between browse and confirm all fail the same live check
and are rejected with `"Can't use this location."` — nothing is ever
persisted from a stale browse-time snapshot.

# EXACT GAME ISOLATION

`gameId` is always explicit end-to-end (client → HTTP body → coordinator
call), never derived from "currently selected Game." Proven by S10-8 (Game A
choice never touches Game B) and S10-9 (an explicit-gameId choice for Game A
succeeds unaffected while the Control Plane's ambient "selected" Game is
Game B). The Browse Game controller additionally closes itself if the
selected Game changes while open (pre-existing `syncOpenGameBrowser`
behavior, unchanged), so a stale in-flight picker for a switched-away Game
cannot even reach the confirm action in the live UI.

# S7 / S9 CONVERGENCE

- **S7**: `/choose` for `kind: 'reports'` calls the existing
  `applyGameFilesystemContract`, sending `game.filesystem.apply` with the new
  path/state/lanes — the exact same push S7/S8 already use. Proven by S10-14
  (apply RPC observed with the new path).
- **S9**: proven end-to-end by S10-15 — a Codex lane established under an
  auto-detected `Reports` root survives a human override to `Existing
  Stuff/My Reports`, and a subsequent Controlled Play dispatch resolves its

  Reports/Codex/` with **zero** S9/router code changes — `resolveCanonicalReportDestination`
  simply reads the updated `contract.reports.path` it already read before.

# RESTORE DETECTED FOLDER

Implemented using the existing `clearChoice` + `reconcile()` seam only — no
new persistence concept, no follow-up gap. `clearChoice` resets the folder to
`{ provenance: 'none', state: 'not-set' }` (lanes preserved for reports);
`/restore` then reuses S6's own reconcile pass so automatic detection
resumes immediately if the Game is connected (S10-20). If the Game happens to
be offline at that moment, the folder correctly shows `Not set` until the
next successful reconcile — this is the same truthful "no evidence yet"
behavior S6 already has everywhere else, not a new state.
