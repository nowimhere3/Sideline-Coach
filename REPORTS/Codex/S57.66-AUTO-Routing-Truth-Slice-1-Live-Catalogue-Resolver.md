# PURE RESOLVER DESIGN

resolveCatalogueRoute(intent, catalogue) accepts an explicit CatalogueRouteIntent derived with Pick<RouteConstraints>: optional Player type, exact instance, model component and effort component. This is not a prompt string API.

It builds the candidate space, intersects Player/instance/model/effort filters, and returns state, all surviving candidates and RouteConstraints-compatible intent. It uses case/punctuation normalization, existing effort aliases, model id/display-name matching, contiguous model token runs, and the architecture's digit-free family/version-decoration rule. Effort narrowing is explicit input truth, not a default.

Brand ownership is inferred dynamically only for a universal token belonging to one multi-model Player and no other Player. An exact model identity remains a model. Adding a differently branded catalogue model disables brand shorthand without changing production vocabulary.

No I/O, timers, mutable module cache, policy call, prompt scan, or mutation of the supplied catalogue occurs.

# UNIQUE / AMBIGUOUS / UNAVAILABLE SEMANTICS

- resolved: each named dimension has one live value. Several candidates may remain when effort, model or exact seat was not named. The resolver retains them rather than filling absent dimensions.
- ambiguous: a named model/Player/effort has several compatible values. Every surviving candidate remains; unresolved metadata records ambiguous and offers up to four named-dimension projections in catalogue order. No favourite is chosen.
- unavailable: intersection is empty. Metadata records unknown model/Player or unsupported effort and carries the supplied raw component. Already-known Player/model dimensions are preserved when the requested effort is unsupported. No replacement route is manufactured.

Model identities are compared as Player/model pairs, so a shared family offered by two Players remains ambiguous even if one model id exactly matches the shorthand. Candidate truth is independent of catalogue order; option display order follows catalogue order as S57.57 specifies.
