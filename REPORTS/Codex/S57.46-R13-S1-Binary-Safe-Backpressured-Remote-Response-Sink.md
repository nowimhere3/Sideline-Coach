## Exact root cause

The synthetic response converted Buffer chunks to UTF-8 strings in both `write()` and `end()`. That corrupted arbitrary binary bytes and UTF-8 byte sequences split between writes. Its `write()` always returned true and response event methods were inert, so producers could not pause before reaching RelayClient's 8 MiB queue kill boundary. Cancellation emitted close only on the synthetic request.

## Binary framing

Buffer and Uint8Array chunks use the existing `chunkB64` frame field directly from their bytes, respecting subview offsets and lengths. Strings retain `chunk`. The same rule applies to `write()` and `end()`; no MIME inference or UTF-8 round trip is used.

## Backpressure

RelayClient returns response queue acceptance to the adapter. At 2 MiB queued serialized frame bytes, response `write()` returns false. A connection-scoped drain subscription signals when the queue reaches 1 MiB or less; responses emit drain only after a prior false write. Subscriptions are removed on finish or cancellation. Existing WebSocket bufferedAmount hysteresis (4 MiB / 2 MiB) and the 8 MiB emergency queue boundary remain unchanged.

The deterministic 20 MiB proof uses a manually paced WebSocket seam, drives the real RelayClient enqueue/flush logic, waits on response drain, bounds the queue to 2 MiB plus one serialized frame, compares the complete received payload byte-for-byte, and confirms the tunnel stays connected. The browser-side relay queue policy is unchanged; its Preview-specific policy belongs to a later slice.

## Cancel / close

Responses now expose real EventEmitter subscriptions plus finish, drain, close, and writable/destroyed state. Relay cancel, tunnel loss, and response destroy close both synthetic request and response exactly once, destroy the request, remove flow subscriptions, and reject subsequent writes. Failed WebSocket sends terminate the unusable tunnel so existing teardown cancels producers. Dispatch failure preserves its error frame and also releases producer work. Existing SSE request-close cleanup remains intact.
