## Behavior implemented

- Preserves declared/running dev-server precedence; static hosting is fallback-only.
- Supports `.sideline/game.json` `staticEntrypoint`, root `index.html`, `public/index.html`, and package `browser`/`main` HTML evidence.
- Excludes dependencies, VCS/Sideline metadata, tests/fixtures, coverage, reports/snapshots, vendor, architecture labs, secrets, hidden trees, and inferred `dist`/`build` output.
- Returns a minimal remembered chooser only when no canonical page exists. Active HTML is only a chooser-order hint.
- Projects titled alternates into the existing Preview sheet; selection reuses the same frame and preserves size/rotate state without changing canonical metadata.
- Uses the existing `toClientUrl` bridge and preserves `directTabOnly`.

## Security verification

- `StaticPreviewServer` uses Node `http`, port `0`, and binds only `127.0.0.1`.
- GET/HEAD only; POST/PUT return 405.
- Lexical and real-path containment reject traversal and symlink escape.
- Null bytes, encoded traversal/backslash escape, dotfiles, `.git`, `.sideline`, `.vscode`, `.env*`, and secret/credential paths are refused.
- MIME coverage verified for HTML, JS/MJS, CSS, JSON, SVG, common images, fonts, text/XML, and WASM.
- One server is reused per Stadium and closed on Game switch and deactivation.
